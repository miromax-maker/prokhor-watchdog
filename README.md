# prokhor-watchdog

Сторож бота «Прохор». Раз в 10 минут GitHub проверяет со стороны, что бот отвечает, и пишет держателю процесса
в VK, если он упал, раз в час, пока лежит, и когда поднимется.

Секретов в коде нет. Всё, что нужно для работы, лежит в секретах репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `HEALTH_URL` | адрес проверки бота (WF-Health в n8n) |
| `VK_ALERT_TOKEN` | токен сообщества тревог |
| `VK_PEER` | VK ID того, кому писать |

Ручной запуск: Actions → prokhor-watchdog → Run workflow.

Источник этих файлов — папка `watchdog/` приватного репозитория проекта.
